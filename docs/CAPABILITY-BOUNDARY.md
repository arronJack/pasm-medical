# 能力边界声明（Capability Boundary Statement）

> 版本：v0.1 · 生成日期：2026-11-20 · 适用对象：`pasm-medical` 0.1.1
> 本文回答一个问题：**这个系统到底能做什么、绝对不能做什么。**
>
> 每条结论都附代码证据。原则是：**写"能做"的必须有实现；写"不能做"的要么代码硬拒，要么明确声明。**
> 目的：防止使用者（患者、医护、集成方、二次开发者）误把辅助工具当诊疗决策系统。

---

## 0. 一句话定位

> **预问诊 / 分诊 / 检验辅助 / 带护栏的资料问答 / 中药规则核对 —— 不是诊断系统，更不是手术决策系统。**

系统自定位见 `pasm_medical/__init__.py:1`（"医院智能诊疗辅助系统的认知服务侧"）、
`service.py:968`（persona.role = "临床辅助"）、`safety.py:34`（所有 AI 输出带"辅助"标记）。

---

## 2. ❌ 明确不能做（禁止用途）

| # | 不能做 | 现状证据 | 误用风险 |
|---|---|---|---|
| N1 | **疾病确诊 / 下诊断结论** | `consult.py:18,433`"不做诊断/不是诊断"；`lab.py:271`"不构成诊断"；预问诊摘要按设计不含 assessment/plan | 无查体、无影像、无临床验证，结论不可靠 |
| N2 | **手术诊断 / 术式推荐 / 术前评估 / 手术风险评分** | 核心源码 ASA/术式/适应症/禁忌症/风险评分**零命中**；"手术"仅见于既往史问诊 `consult.py:147` 与拒答反例 `service.py:325` | 越权诊断；无器械注册；误导临床决策 |
| N3 | **按病程动态推荐治疗方案 / 用药调整** | 全包无"病程/分期/progression"数据模型；`timeline()` 仅历史列表：`service.py:387-394`；分诊是硬编码规则 `consult.py:436-449`；`docs/PLAN.md:205` 属文档宣称未落地 | 无疾病演进建模，推荐无依据 |
| N4 | **影像读片 / 自动给影像结论** | **代码级硬边界**：表/接口无结论字段，结论字段入参 400 硬拒，含反例对照（合规清单 §3） | 无三类证；读片属高风险诊断 |
| N5 | **自动出处置结论 / 处方** | 摘要按设计不含 assessment/plan；ANSWER_SYSTEM 明令不得给处方/调剂量 `llm.py:359-360` | 责任主体缺失 |
| N6 | **替医师签字 / 冒充医师确认** | 只有 PHYSICIAN_CONFIRMED 可 approve；DEMO 标 DEMO 无法冒充 | 破坏责任链与审计 |
| N7 | **作为医疗器械用于临床诊断** | `COMPLIANCE-GATE.md`：器械分类界定、NMPA 注册全 ❌ 未启动 | 法规禁止 |
| N8 | **无来源开放式医疗问答** | 相关性闸门不可用宁可拒答、拒答不调模型 `service.py:349-358,376-378`；护栏自承"挡不住引用正确、内容说错" `llm.py:462-466` | 幻觉输出 |

## 3. 灰色地带（能做但必须谨慎）

| 场景 | 规则 |
|---|---|
| LLM 改写措辞 | 仅做"怎么说"，绝不改变规则决定的内容；模型失败就原样返回（`llm.py:291-320`） |
| 云端 LLM 出网 | 出网前已强制去标识（G2/L1-L5 全套：单点模板脱敏 + L2 扩展识别模式 + L3 出网字段白名单 + L4 云端残留拒发，2026-11-20 落地）；**边界**：中文**裸姓名**与**自由文本地址**都检不出（中文姓名/地址与普通词汇无稳定词形边界，L2 只覆盖"姓名：""住址："这类标签形态）→ 上线云端 provider 前仍须按机构合规评估是否补 NER |
| 演示账号 / 演示数据 | 默认关闭（`application.yml:57`）；绝不可跟随生产部署 |
| 自学习候选 | `MEDICAL_LEARNING_AUTO` 默认关；候选须医师确认 + 人工审核双闸 |

## 4. 给不同使用者的红线提示

- **患者**：本系统给你的分诊/摘要/资料回答**不是诊断**，任何不适以执业医师面诊为准。
- **医护**：AI 输出只是草稿与提醒；结论必须你本人填写并确认，系统不会也不该替你决定。
- **集成方（HIS/EMR/LIS）**：不得把本系统的分诊/摘要当作诊断字段写入病历；不得绕过转人工与确认闸门。
- **二次开发者**：不得删除相关性闸门、引用核验、"辅助"标记、不做诊断声明；这些是防止越权的安全边界。
